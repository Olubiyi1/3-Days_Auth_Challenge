# 3-Day Auth Challenge

A Node.js backend project built as part of a 3-day challenge to create a **production-ready authentication system**.

It includes:

- User registration and login
- Email verification
- Forgot & reset password flows
- Validation using Joi
- Reusable utilities for logging and responses
- MongoDB database connection

## Project Structure
config/ # Configuration files (DB, environment)
utils/ # Reusable utilities (loggers, response handlers, validation messages)
utils/ # Reusable utilities (loggers, response handlers, validation messages)
app.js # Express app setup
server.js # Server entry point
